## ขั้นตอนที่ 1 — อ่านและทำความเข้าใจ Context ก่อนวิเคราะห์

ก่อนเริ่มวิเคราะห์ใดๆ ให้ทำตามขั้นตอนนี้ทีละขั้น:

**1.1 อ่านไฟล์ปรัชญานักลงทุนทุกท่านที่ให้มา**
สำหรับนักลงทุนแต่ละท่าน ให้อ่านและสรุปในใจว่า:
- Core Philosophy คืออะไร? (1–2 ประโยค)
- Decision Framework มีกี่ Step? และเริ่มต้นด้วยคำถามอะไร?
- สิ่งที่ท่านนี้ให้น้ำหนักมากที่สุดคืออะไร?
- สิ่งที่ท่านนี้กลัวที่สุดคืออะไร?

ถ้าไฟล์ปรัชญาไม่มี Section "Decision Framework" ให้สร้าง framework จาก Core Philosophy และ First Principles ที่อ่านมาเอง

**1.2 อ่านข้อมูลหุ้นที่ให้มา**
สรุปในใจว่า:
- ธุรกิจนี้คืออะไร? Business Model เป็นอย่างไร?
- ตัวเลขสำคัญที่เห็นคืออะไร? (Revenue, GP Margin, Net Profit, Cash Cycle, D/E)
- ประเด็นที่ผู้บริหารเน้นย้ำมากที่สุดคืออะไร?
- ความเสี่ยงหลักที่ระบุหรือไม่ได้ระบุในข้อมูลคืออะไร?

**1.3 จับคู่ประเด็นสำคัญของหุ้นกับ lens ของแต่ละนักลงทุน**
ก่อนเริ่มวิเคราะห์ ให้ระบุสั้นๆ ว่า:
- นักลงทุนแต่ละท่านจะ "สนใจ" ประเด็นอะไรเป็นพิเศษในหุ้นนี้?
- ประเด็นไหนที่นักลงทุนแต่ละท่านน่าจะ "กังวล" มากที่สุด?

## ขั้นตอนที่ 2 — วิเคราะห์อิสระทีละท่าน

สำหรับนักลงทุน **ทุกท่าน** ที่ให้มาใน context ให้วิเคราะห์ตามรูปแบบนี้:

---

### [ชื่อนักลงทุน]

**กรอบที่ใช้:** [ระบุ Decision Framework ของท่านนี้ตามที่อ่านมาจากไฟล์ปรัชญา]

วิเคราะห์หุ้นนี้โดย:
1. เดิน Step ตาม Decision Framework ของท่านนี้ทีละขั้น ห้ามข้ามขั้น
2. ใช้ Mental Models และ First Principles ที่ระบุในไฟล์ปรัชญา
3. พูดในสไตล์และภาษาของท่านนี้ — ถ้าท่านมีคำพูดเด็ดหรือ analogy ที่ใช้ประจำ ให้นำมาใช้ได้
4. เมื่อพบจุดที่ข้อมูลไม่เพียงพอ ให้ระบุทันทีว่า "ต้องการข้อมูลเพิ่มในเรื่อง..." แทนการเดา
5. จบด้วยการสรุป Verdict ของท่านนี้พร้อมเหตุผล 2–3 ข้อ

> ประเด็นที่ทุกท่านต้องตอบเกี่ยวกับหุ้นนี้ (ไม่ว่า framework จะต่างกันแค่ไหน):
> - ธุรกิจนี้ **sustainable** ระยะยาวหรือเปล่า?
> - **ผู้บริหาร** น่าเชื่อถือและทำเพื่อผู้ถือหุ้นจริงหรือเปล่า?
> - **Downside** ที่แท้จริงคืออะไร ถ้าสิ่งที่คาดหวังไม่เป็นจริง?

### จุดที่ทุกท่านเห็นตรงกัน

### จุดที่เห็นต่างกัน — และทำไมถึงต่าง
ระบุประเด็นที่แต่ละท่านให้น้ำหนักต่างกัน พร้อมอธิบายว่า
เป็นเพราะ framework ต่างกัน หรือ มองข้อมูลเดียวกันในมุมที่ต่างกัน

### สัญญาณที่ต้องติดตาม (Watchlist)
ระบุ 3–5 KPI หรือ Event ที่จะเป็น signal ว่า Investment Thesis ถูกหรือผิด
พร้อมระบุว่าถ้า signal นั้นเกิดขึ้น ควรทำอะไร (ซื้อเพิ่ม / ถือ / ขาย)

## หมายเหตุ

### การเพิ่มนักลงทุนใหม่
เพียงเพิ่ม URL ใน Section A แล้วรัน prompt ใหม่ — AI จะ:
1. ไปอ่านไฟล์ปรัชญาใหม่ก่อนเสมอ
2. สร้าง framework วิเคราะห์จากสิ่งที่อ่านมาเอง
3. เพิ่มคอลัมน์ใน Verdict Table อัตโนมัติ

### ประเภทข้อมูลหุ้นที่ใช้ได้
- Earnings Call Summary (`.md`)
- Annual Report / 56-1 (`.pdf`)
- Analyst Report (`.pdf` / `.md`)
- ข้อมูลที่ paste โดยตรงใน chat

### แนวคิดการออกแบบ
Prompt นี้ออกแบบให้ AI **อ่านก่อนวิเคราะห์** แทนที่จะ hardcode ประเด็น
เพื่อให้สะท้อนปรัชญาที่แท้จริงของแต่ละท่านได้ตรงกว่า
และรองรับนักลงทุนที่มีสไตล์หลากหลาย ไม่ว่าจะเป็น Value / Growth / Macro / Quantitative

# สรุป DIF Earnings Call Q1 2569

## Executive Summary

กองทุนรวมโครงสร้างพื้นฐานโทรคมนาคมดิจิทัล (DIF) รายงานผลการดำเนินงานไตรมาส 1 ปี 2569 โดยบันทึกรายได้รวม 3,693 ล้านบาท (เทียบเท่ากับไตรมาสที่แล้ว) และกำไรสุทธิ 3,076 ล้านบาท เพิ่มขึ้น 1% เทียบกับไตรมาส 4 ปี 2568 ผู้บริหารอธิบายว่าการเปลี่ยนรูปแบบรับรู้รายได้ (จากรายได้ที่มีกระแสมาเป็นรายได้ค่าเช่า) และการออกจากกำไรที่ยังไม่เกิดขึ้นจากการประเมินสินค้ามูลค่า (~2,000 ล้านบาทในไตรมาส 4) ทำให้ bottom line ลดลง 50% ธนาคารกลางเริ่มเก็บอัตราดอกเบี้ยในช่วงนี้ ซึ่งสนับสนุนกองทุนได้เฉลี่ยดอกเบี้ยลดลง 10% เมื่อเทียบกับไตรมาสก่อน ผู้บริหารระบุว่ายังสามารถจ่ายปันผล 0.22 บาทต่อหน่วยได้อย่างต่อเนื่อง

## Business & Strategic Updates

- **ปรับเปลี่ยนรูปแบบรายได้ (4 สิงหาคม 2568):** กองทุนใช้สิทธิซื้อและรับโอนกรรมสิทธิ์ทรัพย์สิน Pfkt และ AUC มาแล้ว → รายได้เปลี่ยนจากรูปแบบที่มีกระแสค่าใช้จ่ายเป็นรายได้ค่าเช่าเป็นหลัก (43% เสา + 57% FOC)

- **โครงการ Network Optimization (ไตรมาส 2 ปี 2569):** True ดำเนินโครงการที่ทดแทนเสาที่ไม่ใช้งานด้วยเสาที่มีความต้องการจริง → มองในแง่บวก (เสาที่เหลือเป็นทรัพย์สินที่ True ต้องใช้จริงในการให้บริการ) ไม่ส่งผลกระทบต่อปริมาณ/ราคาเช่า

- **การควบรวมในกลุ่ม True:** ได้รับมติจากผู้ถือหน่วยให้แก้ไขสัญญากับ True และปรับปรุงโครงการจัดการกองทุน (เปลี่ยนชื่อคู่สัญญา)

- **ลดความเสี่ยงค่าใช้จ่ายเทียบท่า:** ทำสัญญาเหมาจ่ายค่าย้ายเสากับ True แทนการคิดต่อต้นเสา → ประมาณ 20–22 ล้านบาทต่อปี (ลดลงจากระบบเดิมอย่างมาก)

- **ค่าใช้จ่ายรื้อถอน FOC ที่ไม่ใช้:** ประมาณ 54 ล้านบาทต่อปี (ตัดจากระยะ 60 เดือน) — มีความเสี่ยง แต่ไม่มีนัยเมื่อเทียบกับกำไรรวมของกองทุน

- **อัตราดอกเบี้ยผู้กู้เสมือน:** ปัจจุบัน ~5% เต็มปกติ แนวโน้ม 2 ไตรมาสแรกมี 2 รอบปรับลดแล้ว ล่าสุดธนาคารเก็บค่าคงที่ (ไม่ส่งผลต่อกองทุน เหตุจากการกู้เป็นอัตราคงที่)

## Growth Drivers

- **ความสมดุลของพอร์ตโฟลิโอรายได้:** 43% จากเสาโทรคมนาคม + 57% จากสาย FOC → ลดความพึ่งพาผู้เช่ารายเดียว (แม้ True ครองใหญ่) และสร้างความเสถียร

- **ลักษณะ Monopoly ของการลงทุน:** ทรัพย์สินเสาและสายเส้นใยแสงมีอุปสรรค entry ต่ำและต้นทุนเปลี่ยนสูง → ผู้เช่า (True) มีแรงจูงใจเจรจาต่ออย่างสมเหตุสมผล แม้เมื่อสิ้นสัญญา 2576

- **เงื่อนไขการต่ออัตโนมัติ (FOC):** หากส่วนแบ่ง Broadband ของ True เกิน 33% หรือรายได้ Broadband เกิน 16,500 ล้านบาท → ต้องขยายสัญญา +10 ปี (สูงสุดถึง 2586) → มูลค่าปันผลยืดยาว

- **การลด leverage ผ่านดอกเบี้ยลด:** 2 รอบปรับลดตั้งแต่ธันวาคม ลดค่าใช้จ่ายดอกเบี้ย 10% → สนับสนุนความมั่นคงของปันผล 0.22 บาท/หน่วย

## Important Q&A Highlights

**Q1: เงินกู้ก้อนใหญ่ครบกำหนด 2570 กองทุนมีแผนรีไฟแนนซ์อย่างไร สเปรดและเงื่อนไขเป็นอย่างไร**

A: กองทุนไม่สามารถออกหุ้นกู้ได้ตามข้อจำกัดสำนักงานสลต. → แผนคือ **รีไฟแนนซ์กับสถาบันการเงิน** เทอมปกติ 5 ปี เรื่องสเปรด/เงื่อนไขยังต้องเจรจา ขึ้นอยู่กับระยะเวลาลายเซ่น True ที่เหลืออยู่ → อยากเจรจาให้ได้เทอม/ราคาดีสุดเท่าที่เป็นไปได้ **สำรองเงินปี 2569–2570 ประมาณ 1,482 ล้านบาท/ปี เท่ากัน** (ไม่ใช่ "New Normal" แต่เป็นการเตรียมตัวสำหรับ maturity ที่ชัดเจน)

**Q2: เงื่อนไขต่ออัตโนมัติ FOC (ส่วนแบ่ง Broadband >33% หรือรายได้ >16,500 ล้านบาท) — วัดเมื่อไร ใช้ข้อมูลแหล่งใด มีการต่ออัตโนมัติหรือต้องอนุมัติเพิ่ม**

A: **ชี้วัดที่สิ้นสุดสัญญา (ปี 2576)** → ข้อมูลเชื่อถือได้: Annual Report ของ True + ข้อมูลจาก กสทช. (ส่วนแบ่งตลาด) → **ต่อออกจากเงื่อนไขโดยอัตโนมัติ** (ไม่ต้องอนุมัติใหม่) **ระยะเวลาขยายสูงสุด 10 ปี (สูงสุดถึง 2586) แต่ต้องคำนึงว่าลายเซ่น True เหลืออยู่เท่าไหร่ก็ขยายได้เท่านั้น** — เช่น ถ้าลายเซ่นเหลือ 8 ปี ก็ขยายได้แค่ 8 ปี

**Q3: หลังรับโอนกรรมสิทธิ์ BFKT/AUC รายได้สุทธิจะไม่ต่ำกว่าเดิมใช่หรือไม่ (หักค่าใช้จ่ายที่ดิน/สิทธิ/อื่น)**

A: **ได้รับการยืนยัน** ผู้บริหารสอบทานกับ True 12 เดือนก่อนสิ้นสุดสัญญา → **รายได้เสีย ≥ รายได้เดิม** เพิ่มค่าใช้จ่ายใหม่: ค่าเช่าที่ดิน + ค่าประกัน + ค่าย้ายเสา (ลด 90% จากเดิมด้วยสัญญาเหมา) + ค่ารื้อ FOC 54 ล้านบาท/ปี → **ถือว่ามีนัยน้อยเมื่อเทียบกับกำไร** ผู้บริหารปฏิบัติหลักการลดความเสี่ยง

**Q4: Network Optimization/Tower Swap/ควบรวม True จะกระทบปริมาณ/ราคาเช่าหรือการต่อสัญญา 2576 หรือไม่**

A: **ไม่คาดมีผลกระทบต่อปริมาณและราคา** การที่ True ทดแทนเสาที่ไม่ใช้ด้วยเสาจำเป็นต้องใช้ → **บ่งชี้ว่ากองมีเสาที่ True ต้องการจริง** (เพิ่มความมั่นใจในการต่อสัญญา) ก่อน 2576 ปริมาณ/ราคาผูกติดตามสัญญาเดิม ว่าอ่าธุรกิจ/ภาวะการณ์ของ True ณเวลาสิ้นสัญญา — ถ้า True ยังเป็นผู้ประกอบการหลักและต้องใช้เสาก็น่าจะต่อ

**Q5: นโยบายการสำรองการเงิน (1,482 ล้านบาท) เป็น New Normal หรือเปล่า**

A: **ไม่ใช่ New Normal** — ปี 2569 และ 2570 มีปริมาณเท่ากัน (~1,482 ล้านบาท) เนื่องจาก **2570 หลักการเงินกู้ก้อนใหญ่ครบกำหนด** → ต้องสำรองเพื่อรีไฟแนนซ์ ปี 2571 ขึ้นไป ขึ้นอยู่กับเงื่อนไข/แผนชำระหลังจากรีไฟแนนซ์ → **ผู้บริหารกล่าวว่าถ้า PBDT ดีเพียงพอและอัตราดอกเบี้ยไม่เพิ่ม ก็ยังสามารถจ่ายปันผลในระดับใกล้เคียงเดิม**

## Outlook / Guidance

- **ไม่มี Formal Guidance** แต่ผู้บริหารระบุเจตนา:
  - ความมั่นใจในการเก็บรักษาปันผล **0.22 บาท/หน่วยต่อไปในระยะสั้นถึงกลาง** (ขึ้นอยู่กับผลประโยชน์/ดอกเบี้ย/ภาวะเศรษฐกิจ)
  - **ปี 2570 จะต้องทำการรีไฟแนนซ์ประมาณ 23,000–24,000 ล้านบาท** (ไม่มีการเปลี่ยนแปลงปริมาณเงินกู้ QoQ)
  - **ไตรมาส 2 ปี 2569:** ลงท้ายโครงการ Network Optimization ของ True → ไม่คาดมีกระทบต่อรายได้
  - **ปี 2576:** การต่อสัญญา FOC + ความเป็นไปได้ของการเลื่อยได้ Lease Renewal Clause แล้งบนสภาวะธุรกิจ True ณเวลานั้น

## Key Takeaways for Investors

1. **โครงสร้างรายได้ปรับปรุงแล้ว — ลดความเสี่ยง:** ชาร์จจากรูปแบบเงินสดประจำ (FOC/Lease) มากขึ้น ลดการพึ่งพา True เดี่ยวๆ (43% เสา + 57% FOC) → นำเสนอความเสถียรสูง หากสมมติ True ยังคงต้องใช้ทรัพย์สิน

2. **เงื่อนไขต่ออัตโนมัติเป็นประโยชน์ตั้งแต่เมื่อนี้:** ถ้า Broadband ของ True > 33% หรือรายได้ > 16,500 ล้านบาทในปี 2576 → รับประกันต่อ +10 ปี (สูงสุดถึง 2586) ไม่ต้องเจรจาใหม่ → **ปันผลมีความมั่นใจระยะยาวที่ยุติธรรม**

3. **เงินกู้ครบกำหนด 2570 ต้องวิจารณ์อย่างใกล้ชิด:** Spread/Tenor/Rate ของการรีไฟแนนซ์จะเป็นตัวแปรหลักที่เปลี่ยนแปลงอัตราปันผลไปข้างหน้า → ติดตามข้อมูลข่าวสาร/อัปเดตจากกองทุน เกี่ยวกับความคืบหน้า negotiation

4. **ความสมดุลของดอกเบี้ย:** ปัจจุบัน 2 รอบปรับลดนั้นเป็นประโยชน์ (-10% ค่าใช้จ่ายดอกเบี้ย) ขณะนี้ธนาคารเก็บค่า → **หาก FOMC เดือนหน้าเลิกขึ้นสนใจ ก็ต้องติดตามส่วนขอบของกองทุน**

5. **Capex Optimization ของ True ไม่ใช่คำเตือน:** โครงการเปลี่ยนเสาเสริมสนับสนุนการรับรู้ว่าเสาของกองทุนมีความต้องการจริง → บวกต่อเงื่อนไขเจรจาต่อ 2576 หากท่านขายในสมมติฐานว่า True ต่างหากจะเก็บเสาไว้ ให้ระบึดเหตุผลซึ่งจะตรงกับส่วนหนึ่งของผู้บริหาร

# AIT — บมจ. แอ็ดวานซ์อินฟอร์เมชั่นเทคโนโลยี | Earnings Call Q1/2026

**บริษัท:** บริษัท แอ็ดวานซ์อินฟอร์เมชั่นเทคโนโลยี จำกัด (มหาชน) — Advance Information Technology (AIT)  
**ไตรมาส:** Q1/2026 (Q1/2569)  
**ผู้นำเสนอ:** คุณสุริรัตน์ ปาชยานุกูล (รองกรรมการผู้จัดการใหญ่สายงานการเงิน), คุณสรินทร์ จันทรนิภาพงษ์ (ผู้จัดการอาวุโสฝ่ายเลขานุการบริษัท)

---

## 1. Executive Summary

AIT เป็นบริษัท System Integrator (SI) ชั้นนำของไทย ให้บริการออกแบบและวางระบบ ICT แบบครบวงจร (Turn Key) มาตั้งแต่ปี 2539 และเข้าจดทะเบียนในตลาดหลักทรัพย์ปี 2546 มีทีมงานผู้เชี่ยวชาญกว่า 300 คน ศูนย์บริการ 7 แห่งทั่วประเทศ และมีพันธมิตรเทคโนโลยีชั้นนำระดับโลก อาทิ Cisco (Gold Partner), Huawei, Palo Alto, Fortinet

ใน Q1/2026 รายได้ทรงตัวที่ 1,766 ล้านบาท (+0.2% YoY) Gross Profit เพิ่ม 6% YoY เป็น 346 ล้านบาท (GPM 20.1%) แต่กำไรสุทธิปรับลดเล็กน้อยเหลือ 143 ล้านบาท จากการตั้งสำรองค่าปรับงานล่าช้าเนื่องจากการขาดแคลน Memory Chip ฝ่ายบริหารคาดว่าปัญหานี้กำลังคลี่คลาย ภาพรวม Full-Year ยังคงตามเป้า

## 4. Business & Strategic Updates

**ธุรกิจหลัก — System Integrator:**
- ออกแบบและวางระบบ ICT ครบวงจรให้ลูกค้าภาครัฐ รัฐวิสาหกิจ และเอกชน ครอบคลุม Infrastructure, Cyber Security, Big Data, Data Center & Cloud, IoT
- พันธมิตรเทคโนโลยี: Cisco (Gold Partner), Huawei, HP (Infrastructure), Palo Alto, Fortinet, Trend Micro (Cyber Security), VMware
- ลูกค้าหลัก: PTT, HomePro, Toyota, กองทัพอากาศ, กองทัพเรือ, สปส., กฟผ., AOT, SCB, KBank, NTT, True

**ธุรกิจใหม่ — Carbon:**
- ปลูกป่าเพื่อคาร์บอนเครดิต และ Carbon Management Platform (บริษัท CarbonLink)
- เป็น New Growth Engine ระยะยาว ยังอยู่ในระยะเริ่มต้น

**ปัจจัยพิเศษ Q1:**
- ตั้งสำรองค่าปรับงานล่าช้า เนื่องจากการขาดแคลน Memory Chip — กระทบ GPM เล็กน้อย QoQ
- กำลัง Escalate กับ Supplier เพื่อเร่ง Shipment และเจรจากับลูกค้า

## 5. Growth Drivers

- **Backlog แน่น 5,200 ล้านบาท:** รองรับรายได้ Q2-Q4 ได้ดี ทั้ง Government, State Enterprise และ Enterprise
- **Bidding in Process 4,460 ล้านบาท:** State Enterprise 68% — งานโครงการขนาดใหญ่ที่กำลังรอผล
- **รัฐบาลใหม่:** งานภาครัฐทยอยเข้ามา คาดว่าจะเพิ่มขึ้นตามเสถียรภาพการเมือง
- **Cyber Security:** ความต้องการเพิ่มอย่างต่อเนื่องจากทุกกลุ่มลูกค้า
- **Data Center ต่างชาติ:** โอกาสงาน Hybrid Cloud + Security บางส่วน
- **Carbon Business (ระยะยาว):** ตลาดคาร์บอนเครดิตโตต่อเนื่อง

## 7. Important Q&A Highlights

**Q: งานภาครัฐมีมากขึ้นไหมหลังรัฐบาลใหม่?**  
A: ยังทยอยรับมาตามปกติ ยังไม่เห็นการเพิ่มขึ้นชัดเจน แต่คาดว่าจะดีขึ้นตามเสถียรภาพการเมือง

**Q: ค่าปรับงานล่าช้าจาก Memory Chip ขาดแคลน จะรับภาระเองทั้งหมดไหม?**  
A: AIT กำลัง Escalate กับ Supplier เพื่อเร่ง Shipment และเจรจากับลูกค้า คาดว่าจะสามารถลดผลกระทบได้บางส่วน ที่เหลือตั้งสำรองไว้แล้วใน Q1 ฝ่ายบริหารมีระบบ Early Warning ติดตามโครงการ

**Q: ช่องแคบ Hormuz กระทบมากไหม?**  
A: ค่าขนส่งเป็นสัดส่วนเล็กน้อยของต้นทุนโปรเจค กระทบน้อยมาก แต่ยังต้องติดตาม

**Q: ROA/ROE ปีนี้กับปีที่แล้วต่างกันมากไหม?**  
A: ไม่ต่างมาก ROA ~10% ROE ~13-14% ค่อนข้าง Stable ทุกปี

**Q: Data Center ต่างชาติมาไทย มีโอกาสอะไรให้ AIT บ้าง?**  
A: มีโอกาสบ้างด้าน Hybrid Cloud และ Cyber Security แต่ Data Center ต่างชาติส่วนใหญ่นำทีมตัวเองมา AIT ได้ส่วนน้อย

## 8. Outlook / Guidance

- **Revenue Target ปี 2026:** 6,900 ล้านบาท (เพิ่มจาก 6,800 ล้านปี 2025)
- **Q1 รับไปแล้ว 1,766 ล้านบาท** (ตามสัดส่วน) เหลือ ~5,134 ล้านใน 3 ไตรมาส
- **Backlog 5,200 ล้านบาท:** รองรับเป้าหมายที่เหลือได้ทั้งหมด
- **Memory Chip:** คาดคลี่คลายใน Q2-Q3 ผลกระทบจำกัด
- **Carbon Business:** ระยะยาว ยังไม่ contribute รายได้นัยสำคัญในปีนี้

## 9. Key Takeaways for Investors

1. **ธุรกิจ Stable มาก** — รายได้ ~6,800-7,000 ล้าน/ปี สม่ำเสมอ GPM ~19-20% Net Profit ~500 ล้าน/ปี — เป็นธุรกิจที่ Predictable สูง
2. **Backlog แน่น** — 5,200 ล้านบาท รองรับรายได้ที่เหลือของปีได้ชัดเจน
3. **ROA/ROE ดีสม่ำเสมอ** — ROA ~10%, ROE ~13-14% ใกล้เคียงและดีกว่า Sector เฉลี่ย
4. **ความเสี่ยงหลัก** — การขาดแคลน Memory Chip กระทบงาน Project-based และค่าใช้จ่ายพนักงานที่เพิ่มขึ้น ต้องติดตาม Q2
5. **New Business (Carbon)** — น่าสนใจเชิงกลยุทธ์ระยะยาว แต่ยังไม่มีผลต่อกำไรปีนี้ ยังเป็น Optionality เท่านั้น

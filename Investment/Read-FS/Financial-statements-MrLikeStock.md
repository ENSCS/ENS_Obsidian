## 1. ทำไมต้องอ่านงบการเงิน?

งบการเงินคือ **บันทึกสรุปบัญชีทั้งหมดของกิจการ** ที่ถูกจัดทำตามมาตรฐานสากล ทำให้นักลงทุนทุกสายได้ประโยชน์จากการอ่านงบ ไม่ว่าจะเป็น:

- **สายพื้นฐาน / VI** — ใช้วิเคราะห์มูลค่าที่แท้จริงของกิจการ เลือกหุ้นที่ดีในราคาเหมาะสม
- **สาย Growth** — ดูการเติบโตของรายได้ กำไร และการขยายกิจการ
- **สาย Dividend** — ดูความสามารถในการจ่ายปันผลอย่างยั่งยืน
- **สาย Technical / Swing Trade** — ใช้งบกรองหุ้นที่พื้นฐานดีพอก่อนดู Chart
- **ทุกสาย** — ป้องกันตัวเองจากหุ้นที่งบการเงินมีปัญหา

**3 คำถามที่งบการเงินต้องตอบให้ได้:**

| คำถาม | งบที่ใช้ตอบ |
|---|---|
| 1. กิจการทำมาหากินเก่งไหม? | งบกำไรขาดทุน |
| 2. กิจการมีความแข็งแกร่งพอรอดวิกฤตได้ไหม? | งบแสดงฐานะการเงิน (งบดุล) |
| 3. กำไรที่เห็นเป็นของจริงไหม? | งบกระแสเงินสด |

## 2. ข้อจำกัดของงบการเงินที่ต้องรู้ก่อน

ก่อนวิเคราะห์ ต้องเข้าใจข้อจำกัดเหล่านี้เสมอ:

**งบการเงินเป็นข้อมูลจากอดีต**  
งบที่ประกาศออกมาคือสิ่งที่เกิดขึ้นแล้ว เช่น งบไตรมาส 2 ปี 2024 คือข้อมูลของเดือน เม.ย.–มิ.ย. 2024 เท่านั้น ไม่สามารถบอกอนาคต 100% ได้

**บางรายการใช้ราคาทุน ไม่ใช่ราคาตลาดปัจจุบัน**  
เช่น ที่ดินที่ซื้อมา 20 ปีที่แล้ว ยังบันทึกในราคาเดิม ทั้งที่ราคาตลาดอาจแพงขึ้นมาก

**นโยบายบัญชีต่างกัน ทำให้กำไรต่างกัน**  
บริษัทที่ทำธุรกิจคล้ายกัน แต่เลือกวิธีตัดค่าเสื่อมราคาต่างกัน ทำให้กำไรออกมาต่างกันได้

**ปัจจัยเชิงคุณภาพไม่อยู่ในงบ**  
เช่น ฝีมือผู้บริหาร ความน่าเชื่อถือขององค์กร ความสามารถในการแข่งขัน สิ่งเหล่านี้ต้องวิเคราะห์เพิ่มเติมเอง

> **หลักคิด:** งบการเงินบอกสิ่งที่เกิดขึ้นแล้ว แต่เราใช้มันเป็น "เบาะแส" ในการประมาณอนาคตของกิจการ

## 3. ส่วนประกอบของงบการเงิน

งบการเงินมีทั้งหมด 4 ส่วน แต่ที่นักลงทุนใช้จริงหลักๆ คือ 3 ส่วนแรก:

```
งบการเงิน
├── 1. งบแสดงฐานะการเงิน (Balance Sheet / งบดุล)
│       → บอกสถานะ ณ วันใดวันหนึ่ง (เหมือนถ่ายรูป)
│
├── 2. งบกำไรขาดทุน (Income Statement / P&L)
│       → บอกผลลัพธ์ในช่วงเวลาหนึ่ง (เหมือนเทปวิดีโอ)
│
├── 3. งบกระแสเงินสด (Cash Flow Statement)
│       → บอกการเคลื่อนไหวของเงินสดจริง
│
└── 4. งบแสดงการเปลี่ยนแปลงส่วนของทุน
        → ดูการเปลี่ยนแปลงของส่วนเจ้าของ (ใช้น้อยกว่า)
```

นอกจาก 4 งบนี้ ยังมี **หมายเหตุประกอบงบการเงิน** ซึ่งซ่อนรายละเอียดสำคัญไว้มาก ห้ามมองข้ามเด็ดขาด

**สำคัญ: งบรวม vs งบเฉพาะ**

- **งบรวม (Consolidated)** — รวมบริษัทแม่ + บริษัทลูกทั้งหมด ใช้ในการวิเคราะห์ภาพรวม
- **งบเฉพาะ (Separate)** — เฉพาะบริษัทแม่เท่านั้น ใช้ดูความสัมพันธ์ระหว่างแม่และลูก เช่น การให้ยืมเงินกันระหว่างบริษัท

## 4. งบกำไรขาดทุน — วัดความสามารถทำมาหากิน

### โครงสร้างพื้นฐาน

```
รายได้จากการขาย / ให้บริการ
  (-) ต้นทุนขาย / ต้นทุนบริการ
  ─────────────────────────────
= กำไรขั้นต้น (Gross Profit)

  (-) ค่าใช้จ่ายในการขายและบริหาร (SG&A)
  ─────────────────────────────
= กำไรจากการดำเนินงาน (EBIT)

  (+/-) รายได้/ค่าใช้จ่ายอื่น (ดอกเบี้ย, ภาษี, กำไร/ขาดทุนพิเศษ)
  ─────────────────────────────
= กำไรสุทธิ (Net Profit)
```

### คำศัพท์สำคัญ

| คำศัพท์ | ความหมาย |
|---|---|
| **รายได้ (Revenue)** | เงินที่ได้จากการขายสินค้า/บริการ |
| **ต้นทุนขาย (COGS)** | ต้นทุนโดยตรงในการผลิตสินค้า/บริการ |
| **กำไรขั้นต้น (Gross Profit)** | รายได้ - ต้นทุนขาย |
| **GPM (Gross Profit Margin)** | กำไรขั้นต้น / รายได้ × 100% |
| **EBIT** | กำไรก่อนดอกเบี้ยและภาษี |
| **EBITDA** | กำไรก่อนดอกเบี้ย ภาษี ค่าเสื่อม และค่าตัดจำหน่าย |
| **กำไรสุทธิ (Net Profit)** | กำไรหลังหักทุกอย่างแล้ว |
| **NPM (Net Profit Margin)** | กำไรสุทธิ / รายได้ × 100% |
| **EPS (Earnings Per Share)** | กำไรสุทธิ / จำนวนหุ้นทั้งหมด |

### สิ่งที่ต้องดูในงบกำไรขาดทุน

**1. ดูการเติบโตของรายได้**
- เติบโตกี่ % เมื่อเทียบปีต่อปี (YoY) 
- ถ้าหุ้นเติบโตแรง ต้องดูรายไตรมาส (QoQ) ด้วย
- รายได้ที่ดีควรโตขึ้นเรื่อยๆ อย่างสม่ำเสมอ

**2. ดูคุณภาพกำไร (GPM)**
- GPM บอกว่ากิจการมี "อำนาจในการตั้งราคา" แค่ไหน
- GPM ที่สูงและสม่ำเสมอ = กิจการมี Moat / ความได้เปรียบ
- GPM ที่ลดลงต่อเนื่อง = ต้นทุนสูงขึ้น หรือ แข่งขันลำบากขึ้น

**3. ดูรายการพิเศษ — สำคัญมาก**

> **กำไรพิเศษ** = กำไรที่ไม่ได้มาจากธุรกิจหลัก เช่น ขายสินทรัพย์ได้กำไร, ได้รับเงินประกัน
> 
> **ขาดทุนพิเศษ** = ค่าใช้จ่ายที่ไม่ได้เกิดขึ้นประจำ เช่น ตั้งสำรองหนี้สูญ, ขาดทุนจากการลงทุน

การตัดรายการพิเศษออกช่วยให้เห็น **"กำไรปกติ"** ที่แท้จริงของกิจการ วิธีเช็คว่ามีรายการพิเศษไหม → ไปดูในงบกระแสเงินสดจากกิจกรรมดำเนินงาน (CFO)

### ตัวอย่างการวิเคราะห์

| รายการ | ปีที่แล้ว | ปีนี้ | เปลี่ยนแปลง |
|---|---|---|---|
| รายได้รวม | 1,000 ล้าน | 1,200 ล้าน | +20% ✅ |
| กำไรขั้นต้น | 350 ล้าน | 396 ล้าน | +13.1% |
| GPM | 35% | 33% | -2% ⚠️ ต้องตรวจสอบ |
| กำไรสุทธิ | 100 ล้าน | 180 ล้าน | +80% |
| กำไรพิเศษ (ขายที่ดิน) | 0 | 80 ล้าน | |
| **กำไรปกติ** | **100 ล้าน** | **100 ล้าน** | **0%** ⚠️ |

> สรุป: รายได้โต 20% ดูดี แต่พอตัดกำไรพิเศษออก กำไรปกติไม่โตเลย และ GPM ลดลงด้วย → ต้องติดตาม

## 5. งบแสดงฐานะการเงิน (งบดุล) — วัดความแข็งแกร่ง

### สมการพื้นฐาน

```
สินทรัพย์ = หนี้สิน + ส่วนของเจ้าของ (ทุน)
```

งบดุลแสดง "ภาพถ่าย" ของกิจการ ณ วันปิดงวด เปรียบเทียบ 2 จุดเวลา (ต้นปี vs ปลายปี)

### สินทรัพย์ (Assets)

**สินทรัพย์หมุนเวียน (Current Assets)** — แปลงเป็นเงินสดได้ภายใน 1 ปี

| รายการ | ความหมาย | ข้อควรระวัง |
|---|---|---|
| **เงินสดและรายการเทียบเท่า** | เงินสดในมือ / ฝากธนาคาร | ยิ่งมาก ยิ่งดี |
| **ลูกหนี้การค้า (AR)** | คนที่ค้างเงินกิจการ | ถ้าโตเร็วกว่ารายได้ → ระวัง |
| **สินค้าคงเหลือ (Inventory)** | สินค้าที่เตรียมขาย | ถ้าค้างนาน → เสี่ยงขาดทุนสต๊อก |

> **คำจำกัดความง่ายๆ:** "ลูกหนี้" = คนที่ค้างเงินกิจการเรา / "เจ้าหนี้" = คนที่เราค้างเงินเขา

**สินทรัพย์ไม่หมุนเวียน (Non-Current Assets)** — ใช้ระยะยาวเกิน 1 ปี

| รายการ | ความหมาย | หมายเหตุ |
|---|---|---|
| **ที่ดิน อาคาร อุปกรณ์ (PP&E)** | เครื่องมือทำมาหากิน | มีค่าเสื่อมราคา ยกเว้นที่ดิน |
| **สินทรัพย์ไม่มีตัวตน (Intangibles)** | ลิขสิทธิ์ โปรแกรม ชื่อเสียง | มีค่าตัดจำหน่าย |
| **เงินลงทุนระยะยาว** | หุ้นบริษัทอื่น / พันธบัตร | ดูว่าลงทุนแล้วได้ประโยชน์ไหม |

**ค่าเสื่อมราคา (Depreciation) — เข้าใจให้ชัด**

ค่าเสื่อมราคาคือ "ค่าใช้จ่ายแฝง" ที่ไม่ต้องจ่ายเงินจริงในงวดนั้น แต่หักในงบกำไรขาดทุน

ตัวอย่าง: ซื้อรถยนต์ 600,000 บาท ใช้ 5 ปี  
→ ค่าเสื่อมราคาปีละ = 600,000 / 5 = **120,000 บาท/ปี**

สินทรัพย์ที่ **ไม่มี**ค่าเสื่อมราคา: **ที่ดิน** (อายุการใช้งานไม่จำกัด)

### หนี้สิน (Liabilities)

**หนี้สินหมุนเวียน (Current Liabilities)** — ต้องชำระภายใน 1 ปี

| รายการ | ความหมาย | หมายเหตุ |
|---|---|---|
| **เจ้าหนี้การค้า (AP)** | ที่เราค้างเงินคนอื่น | มีมากนิดหน่อยก็โอเค |
| **เงินกู้ระยะสั้น** | หนี้ที่ครบในปีนี้ | ต้องมีเงินจ่ายพอ |
| **หนี้ระยะยาวที่ครบในปีนี้** | ส่วนของหนี้ยาวที่ครบปีนี้ | ระวังถ้ามาก |

**หนี้สินไม่หมุนเวียน (Non-Current Liabilities)** — ชำระในระยะยาวเกิน 1 ปี

| รายการ | ความหมาย | ข้อควรระวัง |
|---|---|---|
| **เงินกู้ระยะยาว** | กู้ธนาคาร / หุ้นกู้ | ดู D/E ratio |
| **หุ้นกู้ (Debenture)** | ออกหุ้นกู้ขายให้ประชาชน | ดู Credit Rating |

**Rating หุ้นกู้:** AAA > AA > A > BBB (Investment Grade) > BB > B > C (Speculative)  
สำหรับมือใหม่ แนะนำ Investment Grade (BBB ขึ้นไป) เท่านั้น

### ส่วนของเจ้าของ (Equity)

| รายการ | ความหมาย | ข้อสังเกต |
|---|---|---|
| **ทุนจดทะเบียนชำระแล้ว** | หุ้นจริงที่ออกมาแล้ว | ใช้หาจำนวนหุ้น (ดูหน่วยเป็น "หุ้น" ไม่ใช่ "บาท") |
| **กำไรสะสม (Retained Earnings)** | กำไรสะสมตั้งแต่ก่อตั้ง | **สำคัญมาก** — ต้องมีกำไรสะสม ถึงจะจ่ายปันผลได้ |

> **กฎง่ายๆ สำหรับมือใหม่:** เลือกบริษัทที่มีกำไรสะสม และกำไรสะสมโตขึ้นทุกปี

### อัตราส่วนจากงบดุลที่ต้องรู้

**D/E Ratio (Debt-to-Equity)** = หนี้สินรวม / ส่วนของเจ้าของ  
- ยิ่งต่ำ ยิ่งปลอดภัย  
- ธุรกิจทั่วไป: D/E ไม่ควรเกิน 1–2 เท่า  
- ธุรกิจ Non-Bank / ที่พักอาศัย: ยอมรับ D/E สูงกว่า เพราะลักษณะธุรกิจ

**Current Ratio** = สินทรัพย์หมุนเวียน / หนี้สินหมุนเวียน  
- ควร > 1 (มีเงินจ่ายหนี้ระยะสั้นได้)  
- ยิ่งสูง = สภาพคล่องยิ่งดี

## 6. งบกระแสเงินสด — เห็นเงินจริง

งบกระแสเงินสดคือ "เอ็กซเรย์" ของกิจการ บอกว่าเงินสดเคลื่อนไหวอย่างไรจริงๆ ต่างจากงบกำไรขาดทุนที่อาจมีรายการทางบัญชีที่ยังไม่ได้จ่าย/รับเงินจริง

### 3 กิจกรรม

```
งบกระแสเงินสด
├── CFO: กระแสเงินสดจากกิจกรรมดำเนินงาน
│       → ทำธุรกิจแล้วได้เงินสดจริงเท่าไหร่?
│
├── CFI: กระแสเงินสดจากกิจกรรมลงทุน
│       → เอาเงินไปลงทุนอะไร? มีการขายสินทรัพย์ไหม?
│
└── CFF: กระแสเงินสดจากกิจกรรมจัดหาเงิน
        → หาเงินจากไหน? กู้หนี้ หรือ ออกหุ้นเพิ่ม?
```

### กิจกรรมที่ 1: CFO — ดูกำไรเป็นเงินสดจริงไหม

CFO ดีมีความหมาย 2 อย่าง:
1. **กำไรที่เห็นในงบ P&L เป็นเงินสดจริง** (ไม่ใช่แค่ตัวเลขบัญชี)
2. **กำไรมาจากการดำเนินงานหลัก** ไม่ใช่รายการพิเศษ

**หลักการดูง่ายๆ:**

| สถานการณ์ | ความหมาย |
|---|---|
| กำไร P&L บวก + CFO บวก | ✅ ดี — กำไรเป็นเงินจริง |
| กำไร P&L บวก + CFO ลบ | ⚠️ ระวัง — อาจมีปัญหาเก็บเงินไม่ได้ หรือมีรายการพิเศษ |
| กำไร P&L ลบ + CFO บวก | 🔍 ตรวจสอบ — อาจมีค่าใช้จ่ายพิเศษ แต่ธุรกิจยังสร้างเงินสดได้ |

**CFO เป็น Year-to-Date** = สะสมจากต้นปี ไม่ได้แยกรายไตรมาส (ต่างจากงบกำไรขาดทุนที่แยกไตรมาสให้)

**วิธีหารายการพิเศษจาก CFO:**  
ในงบ CFO จะมีรายการปรับปรุง เช่น ค่าเสื่อมราคา, กำไร/ขาดทุนจากการขายสินทรัพย์  
→ ถ้าเห็น "กำไรจากการขายสินทรัพย์ (ติดลบ)" = แปลว่ากำไรใน P&L มีส่วนมาจากการขายของ ไม่ใช่ธุรกิจปกติ

### กิจกรรมที่ 2: CFI — เงินออกไปลงทุนอะไร

CFI มักเป็น "ติดลบ" ในกิจการที่กำลังเติบโต เพราะต้องลงทุนอยู่เรื่อยๆ

สิ่งที่ต้องดูใน CFI:
- **บริษัทลงทุนอะไร?** ลงทุนในสิ่งที่เกี่ยวข้องกับธุรกิจหลักไหม?
- **ลงทุนในสินทรัพย์หรือในหุ้น?** การลงทุนในหุ้นของบริษัทอื่นอาจมีความเสี่ยงสูง
- **ความสัมพันธ์บริษัทแม่-ลูก:** ดูว่ามีการให้ยืมเงินระหว่างกันผิดปกติไหม (ดูงบเฉพาะ)

### กิจกรรมที่ 3: CFF — หาเงินจากไหน

CFF บอกว่าบริษัทหาเงินมาจากไหน:

- **บวก** = กำลังหาเงินเพิ่ม (กู้หรือออกหุ้น)
- **ลบ** = กำลังคืนหนี้หรือจ่ายปันผล

แหล่งเงินหลัก 2 ทาง:
1. **จากหนี้** — กู้ธนาคาร / ออกหุ้นกู้
2. **จากทุน** — เพิ่มทุน (ออกหุ้นใหม่)

**สัญญาณการเพิ่มทุน — ต้องระวัง:**
- บริษัทเพิ่มทุนเพราะมีโครงการใหม่ → พอรับได้
- บริษัทเพิ่มทุนเพราะหนี้เยอะจนจ่ายไม่ไหว → อันตราย (ผู้ถือหุ้นเดิมถูก Dilute)

## 7. หมายเหตุประกอบงบการเงิน — รายละเอียดซ่อนอยู่ที่นี่

หมายเหตุฯ มักหนาหลายร้อยหน้า ไม่ต้องอ่านทุกหน้า แต่ควรดูรายการสำคัญเหล่านี้:

### รายการที่ควรอ่านเสมอ

| รายการ | ทำไมสำคัญ |
|---|---|
| **รายงานความเห็นผู้สอบบัญชี** | อ่านก่อนอ่านงบทุกครั้ง |
| **ลูกหนี้การค้า — อายุหนี้** | บอกความเสี่ยงการเก็บเงินไม่ได้ |
| **สินค้าคงเหลือ** | รายละเอียดสินค้าแต่ละประเภท |
| **เงินกู้ยืมและหุ้นกู้** | อัตราดอกเบี้ย วันครบกำหนด |
| **รายการกับกิจการที่เกี่ยวข้องกัน** | การให้ยืมเงินระหว่างบริษัทในกลุ่ม |
| **ภาระผูกพันและหนี้สินที่อาจเกิดขึ้น** | ความเสี่ยงซ่อนเร้น |

### ประเภทความเห็นผู้สอบบัญชี

| ประเภท | ความหมาย | การตัดสินใจ |
|---|---|---|
| **ไม่มีเงื่อนไข (Unqualified)** | งบถูกต้องตามมาตรฐาน | ✅ ดีที่สุด |
| **มีเงื่อนไข (Qualified)** | มีบางรายการที่ต้องระวัง | ⚠️ ต้องอ่านว่าเงื่อนไขคืออะไร |
| **ไม่แสดงความเห็น / ปฏิเสธ** | ผู้สอบบัญชีไม่สามารถรับรองได้ | 🚨 อันตราย — ต้องระวังอย่างมาก |

> **กฎเหล็ก:** อ่านรายงานผู้สอบบัญชีก่อนเสมอ ก่อนดูงบใดๆ

### การดูอายุลูกหนี้ (Aging Analysis)

ในหมายเหตุฯ จะมีตารางแสดง:

| ลูกหนี้ค้างนาน | ความเสี่ยง |
|---|---|
| ยังไม่ถึงกำหนด | ปกติ |
| ค้าง 1–90 วัน | ติดตามได้ |
| ค้าง 91–180 วัน | ⚠️ ระวัง |
| ค้าง 181 วัน–1 ปี | ⚠️ ระวังมาก |
| ค้างเกิน 1 ปี | 🚨 เสี่ยงสูงมาก — อาจต้องตั้งสำรองหนี้สูญ |

## 8. อัตราส่วนทางการเงินที่ต้องรู้

### กลุ่มที่ 1: ความสามารถทำกำไร (Profitability)

| อัตราส่วน | สูตร | ความหมาย |
|---|---|---|
| **GPM** | กำไรขั้นต้น / รายได้ × 100% | ยิ่งสูง = ควบคุมต้นทุนดี มี Moat |
| **NPM** | กำไรสุทธิ / รายได้ × 100% | กำไรสุทธิจากทุกๆ 100 บาทที่ขาย |
| **ROE** | กำไรสุทธิ / ส่วนของเจ้าของ × 100% | ผลตอบแทนต่อทุน (ยิ่งสูง ยิ่งดี) |
| **ROA** | กำไรสุทธิ / สินทรัพย์รวม × 100% | ประสิทธิภาพการใช้สินทรัพย์ |

### กลุ่มที่ 2: สภาพคล่อง (Liquidity)

| อัตราส่วน | สูตร | เกณฑ์ |
|---|---|---|
| **Current Ratio** | สินทรัพย์หมุนเวียน / หนี้สินหมุนเวียน | ควร > 1 |
| **Quick Ratio** | (สินทรัพย์หมุนเวียน - สินค้าคงเหลือ) / หนี้สินหมุนเวียน | ควร > 0.8 |

### กลุ่มที่ 3: โครงสร้างทางการเงิน (Leverage)

| อัตราส่วน | สูตร | เกณฑ์ทั่วไป |
|---|---|---|
| **D/E Ratio** | หนี้สินมีดอกเบี้ย / ส่วนของเจ้าของ | ควร < 1–2 (ขึ้นกับอุตสาหกรรม) |
| **Interest Coverage** | EBIT / ดอกเบี้ยจ่าย | ควร > 3 |

### กลุ่มที่ 4: การประเมินมูลค่า (Valuation)

| อัตราส่วน | สูตร | หมายเหตุ |
|---|---|---|
| **P/E Ratio** | ราคาหุ้น / EPS | ยิ่งต่ำ ยิ่งถูก (เทียบกับกลุ่มเดียวกัน) |
| **P/BV** | ราคาหุ้น / มูลค่าตามบัญชีต่อหุ้น | หุ้นที่ P/BV < 1 = ซื้อต่ำกว่ามูลค่าทางบัญชี |
| **Dividend Yield** | เงินปันผลต่อหุ้น / ราคาหุ้น × 100% | ยิ่งสูง ยิ่งน่าสนใจสำหรับสาย Dividend |
| **EV/EBITDA** | Enterprise Value / EBITDA | เปรียบเทียบข้ามบริษัทได้ดีกว่า P/E |

### การเปรียบเทียบที่ถูกต้อง

- เปรียบเทียบกับ **คู่แข่งในอุตสาหกรรมเดียวกัน** เสมอ
- เปรียบเทียบกับ **ประวัติของบริษัทเอง** ย้อนหลัง 3–5 ปี
- **Fair PE** — ดูจากค่าเฉลี่ยของกลุ่มอุตสาหกรรม บริษัทที่เติบโตดีกว่าควรได้ PE สูงกว่า

## 9. ขั้นตอนวิเคราะห์งบการเงินแบบ Step-by-Step

### ภาพรวม: ลำดับการวิเคราะห์

```
STEP 1: ศึกษาธุรกิจก่อน
         ↓
STEP 2: อ่านรายงานผู้สอบบัญชี
         ↓
STEP 3: ดูสรุป MD&A ของฝ่ายจัดการ
         ↓
STEP 4: วิเคราะห์งบกำไรขาดทุน
         ↓
STEP 5: วิเคราะห์งบกระแสเงินสด
         ↓
STEP 6: วิเคราะห์งบดุล
         ↓
STEP 7: ดูหมายเหตุประกอบงบการเงิน
         ↓
STEP 8: คำนวณอัตราส่วนทางการเงิน
         ↓
STEP 9: สรุปและประเมินมูลค่า
```

---

### STEP 1: ศึกษาธุรกิจก่อนวิเคราะห์งบ

**ต้องรู้ก่อนวิเคราะห์:**
- บริษัทนี้ทำธุรกิจอะไร?
- รายได้มาจากไหน? (สัดส่วนแต่ละ segment)
- คู่แข่งคือใคร? อยู่ใน Industry ไหน?
- มี Opportunity Day / Analyst Meeting ให้ฟังไหม?

> **เคล็ดลับ:** ถ้าบริษัทมี Opportunity Day ให้ฟังด้วยเสมอ จะเข้าใจธุรกิจได้เร็วขึ้นมาก

---

### STEP 2: อ่านรายงานผู้สอบบัญชี

**ทำก่อนทุกครั้ง** — ดูว่าเป็น "ไม่มีเงื่อนไข" หรือเปล่า  
ถ้ามีเงื่อนไข ต้องอ่านว่าเงื่อนไขนั้นคืออะไรก่อนวิเคราะห์ต่อ

---

### STEP 3: ดูสรุปฝ่ายจัดการ (MD&A)

บางบริษัทเขียน MD&A ละเอียดมาก ช่วยให้เข้าใจสาเหตุของการเปลี่ยนแปลงได้โดยไม่ต้องดูงบจริง  
**ถ้า MD&A ดีพอ ดูตรงนี้แล้วจบได้เลย** สำหรับบางกรณี

---

### STEP 4: วิเคราะห์งบกำไรขาดทุน

**Checklist:**
- [ ] รายได้ YoY เป็น + หรือ -? กี่ %?
- [ ] ถ้าโตแรง ดู QoQ ด้วย
- [ ] GPM เปลี่ยนไปทิศทางไหน?
- [ ] มีรายการพิเศษไหม? ถ้ามีตัดออกแล้วกำไรปกติเป็นเท่าไหร่?
- [ ] EPS เป็นเท่าไหร่?

---

### STEP 5: วิเคราะห์งบกระแสเงินสด

**Checklist:**
- [ ] CFO เป็น + หรือ -?
- [ ] CFO เทียบกับกำไรสุทธิ มากกว่าหรือน้อยกว่า?
- [ ] CFI: บริษัทลงทุนอะไร? ลงทุนในธุรกิจที่เกี่ยวข้องไหม?
- [ ] CFF: มีการกู้เพิ่มหรือคืนหนี้?
- [ ] มีรายการพิเศษที่ต้องตรวจสอบไหม?

---

### STEP 6: วิเคราะห์งบดุล

**Checklist:**
- [ ] สินทรัพย์รวมโตขึ้นหรือลดลง?
- [ ] ลูกหนี้การค้าโตเร็วกว่ารายได้ไหม? (ระวัง)
- [ ] สินค้าคงเหลือเพิ่มขึ้นผิดปกติไหม?
- [ ] D/E Ratio เป็นเท่าไหร่? อยู่ในระดับที่ยอมรับได้ไหม?
- [ ] กำไรสะสมเป็น + หรือ -?
- [ ] มีหนี้ระยะสั้นจำนวนมากที่ครบกำหนดในปีนี้ไหม?

---

### STEP 7: ดูหมายเหตุสำคัญ

**ต้องดูเสมอ:**
- [ ] อายุลูกหนี้การค้า (Aging)
- [ ] รายละเอียดหนี้กู้ยืม (อัตราดอกเบี้ย วันครบกำหนด)
- [ ] รายการระหว่างกันกับบริษัทเกี่ยวข้อง

---

### STEP 8: คำนวณอัตราส่วนทางการเงิน

เปรียบเทียบกับ:
1. ปีก่อนๆ ของบริษัทเดียวกัน (ดูเทรนด์)
2. คู่แข่งในอุตสาหกรรมเดียวกัน (ดูความได้เปรียบ)

---

### STEP 9: สรุปและประเมินมูลค่า

**วิธีง่ายสำหรับมือใหม่:**

1. ประมาณ EPS ทั้งปี (จากข้อมูลครึ่งปีหรือ 3 ไตรมาสที่มี)
2. หา Fair PE จากค่าเฉลี่ยของกลุ่มอุตสาหกรรม
3. คำนวณ Fair Price = EPS × Fair PE
4. เปรียบเทียบกับราคาตลาดปัจจุบัน
5. ถ้าราคาตลาดต่ำกว่า Fair Price มาก → น่าสนใจ
6. รอซื้อที่ราคาแนวรับ / จุดต่ำของกรอบ → Cost of entry ดีขึ้น

## 10. สัญญาณอันตราย vs สัญญาณดี

### 🟢 สัญญาณดี — น่าลงทุน

- รายได้เติบโตสม่ำเสมอทุกปี
- GPM อยู่ในระดับสูงและคงที่หรือสูงขึ้น
- CFO > กำไรสุทธิ (กำไรเป็นเงินสดจริง)
- D/E ต่ำ หนี้อยู่ในระดับที่จัดการได้
- กำไรสะสมเป็นบวกและเพิ่มขึ้นทุกปี
- ลูกหนี้โตสอดคล้องกับรายได้
- ผู้สอบบัญชีให้ความเห็น "ไม่มีเงื่อนไข"
- บริษัทลงทุนในสิ่งที่เกี่ยวข้องกับธุรกิจหลัก

### 🔴 สัญญาณอันตราย — ต้องระวัง

- กำไรโต แต่ CFO ติดลบ หรือต่ำมาก
- ลูกหนี้การค้าเพิ่มขึ้นเร็วกว่ารายได้
- สินค้าคงเหลือเพิ่มขึ้นผิดปกติ
- D/E สูงขึ้นเรื่อยๆ โดยไม่มีเหตุผลชัดเจน
- กำไรสะสมติดลบ (ขาดทุนสะสม)
- กำไรดีขึ้น แต่มาจากรายการพิเศษ 100%
- ลูกหนี้ค้างชำระเกิน 1 ปีมีสัดส่วนสูง
- บริษัทลงทุนในสิ่งที่ไม่เกี่ยวกับธุรกิจหลัก และขาดทุน
- บริษัทแม่ให้ยืมเงินบริษัทลูกจำนวนมาก และไม่มีการคืน
- ผู้สอบบัญชีให้ความเห็นแบบ "มีเงื่อนไข" หรือ "ปฏิเสธ"

## 11. การประยุกต์ใช้กับการลงทุนแต่ละสาย

### สาย Value Investing (VI)

**จุดโฟกัสหลัก:**
- หา Intrinsic Value เทียบกับราคาตลาด
- ดูหุ้นที่ราคาต่ำกว่ามูลค่าจริง (Margin of Safety)

**งบที่สำคัญ:**
- งบดุล — ดูสินทรัพย์สุทธิ (Net Asset Value)
- งบกำไรขาดทุน — ดู Normalized Earnings
- คำนวณ P/BV, P/E เทียบกับมูลค่าที่แท้จริง

### สาย Growth Investing

**จุดโฟกัสหลัก:**
- รายได้เติบโตเร็วและยั่งยืน
- บริษัทมีโอกาสในการขยายธุรกิจ

**งบที่สำคัญ:**
- งบกำไรขาดทุน — ดูอัตราการเติบโต YoY และ QoQ
- CFI — ดูว่าลงทุนในอะไร สร้างการเติบโตในอนาคตไหม
- ยอมรับ P/E สูงได้ ถ้าเชื่อมั่นในการเติบโต

### สาย Dividend Investing

**จุดโฟกัสหลัก:**
- ปันผลสม่ำเสมอและยั่งยืน
- กิจการมีกระแสเงินสดเพียงพอ

**งบที่สำคัญ:**
- กำไรสะสมต้องเป็นบวก
- CFO ต้องแข็งแกร่ง — เป็นแหล่งเงินจ่ายปันผล
- D/E ต้องไม่สูงเกินไป เพื่อให้บริษัทยังจ่ายปันผลได้
- ดู Payout Ratio (% ของกำไรที่จ่ายเป็นปันผล) ไม่ควรเกิน 80%

### สาย Swing Trade / Technical

**จุดโฟกัสหลัก:**
- กรองหุ้นที่พื้นฐานไม่แย่ ก่อนดู Chart

**งบที่ใช้:**
- ดูกำไรสุทธิว่าเป็นบวกหรือเปล่า
- D/E ไม่สูงเกินไป
- ผู้สอบบัญชีให้ความเห็น "ไม่มีเงื่อนไข"
- ไม่ต้องลงลึกมาก แต่ต้องไม่ลงทุนหุ้นที่พื้นฐานมีปัญหา

## 12. วิธีหางบการเงินจากเว็บไซต์ SET

### ขั้นตอน (ใช้ SET Website)

1. ไปที่ `www.set.or.th`
2. ค้นหาชื่อย่อหุ้น เช่น `PR9`, `CPALL`
3. กดเข้าหน้าหุ้น → เลือก "งบการเงิน" หรือ "ข้อมูลทางการเงิน"
4. สำหรับข้อมูลสรุป: ดูหน้า "สรุปข้อสนเทศ" → รายการทางการเงิน
5. สำหรับงบจริง: กดดาวน์โหลด งบการเงิน (F45) หรือ One Report

### ทำไมดู MD&A ก่อน

ในหน้าข้อมูลหุ้นจะมี "คำอธิบายและการวิเคราะห์ของฝ่ายจัดการ (MD&A)"  
บริษัทที่ดีจะเขียน MD&A ละเอียด อธิบายสาเหตุทุกการเปลี่ยนแปลง  
→ อ่านตรงนี้ก่อน ถ้าเพียงพอก็ไม่จำเป็นต้องเปิดงบจริงทั้งหมด

### การเปรียบเทียบ YoY และ QoQ

| การเปรียบเทียบ | ความหมาย | ใช้เมื่อไหร่ |
|---|---|---|
| **YoY (Year-on-Year)** | ไตรมาสนี้ เทียบกับ ไตรมาสเดียวกันปีที่แล้ว | ใช้เป็นหลัก — ขจัดผลฤดูกาล |
| **QoQ (Quarter-on-Quarter)** | ไตรมาสนี้ เทียบกับ ไตรมาสก่อนหน้า | ใช้เมื่อหุ้นกำลังเติบโตแรง |

## ภาคผนวก: คำศัพท์ที่ต้องจำ

| คำศัพท์ | ภาษาอังกฤษ | ความหมายสั้นๆ |
|---|---|---|
| สินทรัพย์ | Assets | สิ่งที่กิจการมี |
| หนี้สิน | Liabilities | ภาระที่ต้องจ่าย |
| ส่วนของเจ้าของ | Equity | สินทรัพย์ - หนี้สิน |
| รายได้ | Revenue / Sales | เงินจากการขายสินค้า/บริการ |
| ต้นทุนขาย | COGS | ต้นทุนโดยตรง |
| กำไรขั้นต้น | Gross Profit | รายได้ - COGS |
| กำไรสุทธิ | Net Profit | กำไรหลังหักทุกอย่าง |
| กำไรต่อหุ้น | EPS | กำไรสุทธิ / จำนวนหุ้น |
| อัตราส่วนราคาต่อกำไร | P/E Ratio | ราคาหุ้น / EPS |
| กระแสเงินสดจากดำเนินงาน | CFO | เงินสดจากธุรกิจหลัก |
| กระแสเงินสดจากลงทุน | CFI | เงินสดจากการลงทุน |
| กระแสเงินสดจากจัดหาเงิน | CFF | เงินสดจากกู้/ออกหุ้น |
| ค่าเสื่อมราคา | Depreciation | ค่าใช้จ่ายแฝงของสินทรัพย์ถาวร |
| ค่าตัดจำหน่าย | Amortization | ค่าใช้จ่ายแฝงของสินทรัพย์ไม่มีตัวตน |
| กำไรสะสม | Retained Earnings | กำไรสะสมตลอดอายุกิจการ |
| ลูกหนี้การค้า | Accounts Receivable (AR) | คนที่ค้างเงินกิจการ |
| เจ้าหนี้การค้า | Accounts Payable (AP) | คนที่กิจการค้างเงิน |
| สินค้าคงเหลือ | Inventory | สินค้าที่เตรียมขาย |
| หุ้นกู้ | Debenture / Bond | ตราสารหนี้ที่บริษัทออก |
| อัตราส่วนหนี้ต่อทุน | D/E Ratio | วัดภาระหนี้ |
| ผลตอบแทนต่อส่วนของเจ้าของ | ROE | กำไร / ส่วนของเจ้าของ |
| ผลตอบแทนต่อสินทรัพย์ | ROA | กำไร / สินทรัพย์รวม |
| เงินปันผล | Dividend | เงินที่บริษัทแจกให้ผู้ถือหุ้น |
| Free Cash Flow | FCF | CFO - CapEx |
| Capital Expenditure | CapEx | การลงทุนในสินทรัพย์ถาวร |
| Year-on-Year | YoY | เปรียบเทียบปีต่อปี |
| Quarter-on-Quarter | QoQ | เปรียบเทียบไตรมาสต่อไตรมาส |

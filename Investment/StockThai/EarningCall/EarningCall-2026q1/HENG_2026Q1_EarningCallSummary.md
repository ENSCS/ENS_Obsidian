# สรุป Earnings Call Q1/2026 — HENG

---

## Executive Summary

HENG ประสบความสำเร็จในไตรมาส 1 ปี 2569 โดยกลับมามีกำไรสุทธิ **63.1 ล้านบาท** (margin 15.2%) หลังจากขาดทุนในไตรมาส 4 ที่ผ่านมา ผลลัพธ์นี้ขับเคลื่อนโดยการลดค่าใช้จ่ายการดำเนินงาน **37.1% YoY** ด้านหลัก — ลดจำนวนสาขาจาก 743 เหลือ 450 สาขา ลดการสูญเสีย ECL และขาดทุนจากการจำหน่ายสินทรัพย์ ในขณะที่รายได้ลดลง 31.3% YoY เนื่องจากพอร์ตสินเชื่อหดตัว 8.3% มาที่ 8,612 ล้านบาท

ผู้บริหารประกาศเปลี่ยนกลยุทธ์จาก "ปริมาณ" เป็น "คุณภาพ" — มุ่งปล่อยสินเชื่อที่เข้มงวดกว่า คัดกรองลูกค้าอย่างชาญฉลาด ลดค่าใช้จ่าย และขยายช่องทางจัดหาลูกค้าผ่านพันธมิตร (เต็นท์รถ ร้านค้าเกษตร) เป้าหมายระยะกลางคือลดหนี้เงินกู้เหลือ 0.3 เท่า ปล่อยปันผล และสร้างความสามารถในการทำกำไรที่ยั่งยืน

## Business & Strategic Updates

### **กลยุทธ์หลัก: จากปริมาณเป็นคุณภาพ**
- เปลี่ยนทิศทางจากขยายตัวเชิงปริมาณไปเป็นการปล่อยสินเชื่อคุณภาพสูง (quality over quantity)
- คัดกรองลูกค้าเข้มงวด: ตรวจสอบรายได้ชัดเจน ความสามารถชำระหนี้ OSR อย่างน้อย 70% (ไม่ให้ถึง 100%) มีเงินเหลือเผื่อเหตุฉุกเฉิน

### **ปรับโครงสร้างเครือข่าย**
- ปิดสาขาที่ไม่มีประสิทธิภาพ: 293 สาขา (จาก 743 → 450) เพื่อลดค่าใช้จ่ายการดำเนินงาน
- ขยายพันธมิตร (Channel Partners): เต็นท์รถ (6,000 แห่ง) ร้านค้าเกษตร (2,500 แห่ง) ที่ขายปุ๋ยและอุปกรณ์ และเครื่องใช้ไฟฟ้า (1,000 แห่ง) เป็นตัวแทนแทนสาขา
- ประเด็น: บริษัทมั่นใจว่าสาขาใกล้เคียงและพันธมิตรสามารถบริการลูกค้ากลุ่มเดียวกันได้

### **ปรับปรุงกระบวนการจัดเก็บหนี้**
- พัฒนากลยุทธ์จัดเก็บ: คำนึงรายได้ลูกค้าตั้งแต่ช่วงปล่อยสินเชื่อเพื่อให้สอดคล้องกับภาระหนี้
- ใช้ไอที/เทคโนโลยี: ข้อมูลการเก็บหนี้แบบ real-time ทุกวัน แจ้งเตือนลูกค้าที่ชัดเจน
- มาตรการปรับปรุงโครงสร้างหนี้ (PDR): ยังคงให้บริการลูกค้าที่ยากเข้มขัดเพื่อลดการไหลตกและเลื่อนชั้น NPL ขึ้นมา Stage 1

### **นโยบายสินเชื่อตามเป้าหมาย**
- เน้นกลุ่มเกษตรกร เนื่องจากเป็นกลุ่มเป้าหมายที่มีคุณภาพดี
- ปล่อยสินเชื่อเฉพาะเจาะจง: สินเชื่อการเกษตร สินเชื่อเครื่องปรับอากาศ เพื่อสนับสนุนธุรกิจ nano-finance ของลูกค้า

### **ความปลอดภัยและการกำกับดูแล**
- ESG Rating: 3A ตัวอักษร (สูง)
- CG Rating: 5 ดาว (excellent)
- ระดับ Sustainability: ดีดีเลิศสม่ำเสมอเป็น 4 ปีติดต่อกัน
- AGM Checklist: 100 คะแนนเต็ม เป็น 4 ปีติดต่อกัน
- Future Train Award ปี 2026 + Green Label (กระทรวงทรัพยากรและสิ่งแวดล้อม) + CAC (บริษัทที่ดำเนินการตามหลักการ)

## Growth Drivers

1. **การลดต้นทุน + เพิ่มประสิทธิภาพ**: ปิดสาขาขาดทุน ลดพนักงานด้อยประสิทธิภาพ → ค่าใช้จ่ายลง 37% YoY → กำไรหารดขึ้น 20% YoY แม้รายได้ลง 31%

2. **คุณภาพหนี้ดีขึ้น**: ปล่อยเข้มงวด คัดกรองลูกค้า ติดตามจัดเก็บใกล้ชิด → NPL ลดจาก 7.5% → 7.3% → Stage 1 เพิ่มจาก ~65% → 73.4% → ECL เพิ่มเรื่องเล็กลง → ลดความเสี่ยงขาดทุน

3. **Debt Reduction**: ชำระหนี้เงินกู้อย่างสม่ำเสมอ → Debt-to-Equity ลดจาก 0.72 → 0.66 → เป้าปลายปี ~0.3 → อิสระหนี้ = โอกาส dividend + flexibility ทางการเงิน

4. **Channel Expansion**: แทนสาขาด้วยพันธมิตร (เต็นท์ รร้านค้าเกษตร) → ลดค่า overheads แต่ยังสามารถเข้าถึงลูกค้านอกสาขาได้ → ไม่หดตัวความสามารถในการหาลูกหนี้

5. **Sustainable Growth**: กำลังสร้างธุรกิจที่เล็กลงแต่กำไรเพิ่มขึ้น + cash flow ดี + หนี้ลดลง = แม่บทที่เข้มแข็งสำหรับปันผลและการเติบโตระยะยาว

## Important Q&A Highlights

**Q: แนวโน้ม NPL สินเชื่อเช่าซื้อรถยนต์ในปัจจุบัน?**  
A: ปัจจุบันบริษัทเน้นจำนำทะเบียน (ไม่สินเชื่อเช่าซื้อใหม่เยอะ) → สัดส่วนเช่าซื้อลดลง NPL รวมอยู่ 7.3% คาดการณ์สิ้นปี 6–7% ด้วยคุณภาพหนี้ปัจจุบันและมาตรการจัดการ

**Q: หลังมาตรการ "คุณสู้เราช่วย" (รัฐบาล) สิ้นสุดแล้ว NPL จะปรับตัวสูงขึ้นมากหรือ?**  
A: บริษัทไม่ได้เข้าร่วมมาตรการคุณสู้เราช่วย แต่มีมาตรการ PDR ของตัวเองตั้งแต่แต่ก่อน → ช่วยลูกหนี้ยังสามารถชำระได้ + ป้องกันไหลตก → NPL ปรับลดจาก 7.5% → 7.3% เป็นหลักฐานประสิทธิภาพ

**Q: LTV (Loan-to-Value) จำนำทะเบียนสูงสุดกี่เปอร์เซ็นต์?**  
A: (คุณวิชัย) โดยเฉลี่ยอยู่ ~75% แต่บางรายถึง 80–90% น้อยคน อย่างไรก็ตาม คุณวิชัยเน้น: ความสามารถชำระหนี้เป็นหลัก → ยอม OSR 70% (ไม่ 100%) เพื่อให้ลูกค้ามีเงินเผื่อเหตุฉุกเฉิน (รถเสีย ป่วย ฯลฯ) → อดีตให้ถึง 100% → ตอนนี้เคร่งครัดขึ้น = คุณภาพลูกหนี้ดีขึ้น

**Q: ภายใต้ความผันผวนราคารถยนต์ บริษัทมีนโยบายประเมินความเสี่ยงต่างกันระหว่าง "สันดาน vs EV" หรือไม่?**  
A: ตอนนี้บริษัท 100% ทำแค่รถสันดาน ไม่ทำ EV ยัง → ไม่มีข้อกังวลในเรื่องนี้

**Q: สำหรับท่านนักลงทุน (Summary)**  
(คุณวิชัย) สรุป outlook ของบริษัท:
- ลดต้นทุน + เพิ่มประสิทธิภาพ → พอร์ตจะเล็กลง แต่กำไรเพิ่มขึ้น
- ลด Debt-to-Equity จาก 2.0 เท่า (อดีต) → ปัจจุบัน 0.66 → เป้าปลายปี ~0.3
- ถ้าดำเนินต่อวิธีนี้ หนี้อาจหมดไป ขณะพอร์ตหดเหลือ ~7,000 ล้านจาก ~15,000 ล้านสูงสุด
- ผลลัพธ์: กำไรหารดก่อน ปันผล เพิ่มขึ้นตั้งแต่ปีนี้ → เดินหน้า

## Outlook / Guidance

- **NPL Target สิ้นปี**: 6–7% (จากปัจจุบัน 7.3%)
- **Debt-to-Equity Target สิ้นปี**: ~0.3 เท่า (จากปัจจุบัน 0.66)
- **ปันผล**: ผู้บริหารระบุว่า "จะสามารถปันผลได้เพิ่มขึ้นตั้งแต่ปีนี้" (ไม่มี rate ที่แน่นอน)
- **กลยุทธ์ระยะกลาง**: ยังเน้นคุณภาพ ไม่ใช่ปริมาณ → ปล่อยสินเชื่อใหม่จะยังต่ำ → พอร์ตอาจเหลือ ~7,000 ล้านบาท
- **Formal Guidance**: ผู้บริหารไม่ได้ให้ guidance อย่างเป็นทางการ

## Key Takeaways for Investors

1. **กลับมาเป็นกำไร + ดีขึ้นอย่างชัดเจน**: Q1 กำไร 63.1 ล้านบาท (ขาดจาก -ไม่ระบุจำนวน Q4) → เสนอภาพลดต้นทุนมีประสิทธิผล ควร monitor Q2 onwards ว่ายืดยาวได้หรือไม่

2. **คุณภาพหนี้โดยพื้นฐาน Improving**: NPL 7.3% → 6–7% target + Stage 1 73.4% + ECL ลด → เสี่ยงหนี้สูญลดลง ตัวตั้ง reserve อาจเล็กลงต่อไป = upside กำไร

3. **หนี้ลดอย่างเห็นได้ชัด**: Debt-to-Equity 0.66 → 0.3 target = บริษัทกำลังเดินเข้าหาการปลอดหนี้ → ปันผลใกล้มาเลย ตรวจสอบ Dividend Policy ต่อไป

4. **ความเสี่ยง: Organic Growth ชะลอ**: ปล่อยสินเชื่อใหม่ต่ำเจตนา (คุณภาพไม่ปริมาณ) → พอร์ต 8,612 ล้านอาจจะเหลือ 7,000 ล้านต่อเมื่อสิ้นปี → ลดลง 18–20% อีก เสี่ยง Revenue ลดต่อเนื่อง แม้กำไรอาจหารดก่อน

5. **Management Credibility**: CEO/CFO บอกตรง ว่าจะ sacrifice ธุรกิจขนาดเพื่อกำไรคุณภาพ + dividend → ดูเป็นกลยุทธ์ตั้งใจ ไม่ใช่ผลพลอยได้ อย่างไรก็ตาม execution ของ channel partners (เต็นท์/ร้านค้า) ต้อง monitor ว่าเบิก QA/QC ได้เหมือนสาขาหรือไม่
